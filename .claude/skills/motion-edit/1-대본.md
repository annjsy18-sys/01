# 1. 대본

## 길이
- **10~13줄**, 읽었을 때 **40~60초**.

## 줄별 규칙

| 줄 | 규칙 | 예시 |
|---|---|---|
| 1줄 | **"여러분,"** + **2초 안에 끝나는 센 한마디**. 매번 다른 말로 쓴다(이전 영상 첫 줄과 겹치지 않게). | "여러분, 이거 진짜 큰일 났어요." |
| 2줄 | **충격 + 바로 이유**. "~가 발칵 뒤집혔어요, ~가 풀렸거든요" 꼴. | "지금 업계가 발칵 뒤집혔어요, 이 기능이 무료로 풀렸거든요." |
| 3줄~ | 날짜·숫자 설명은 **3줄부터** 넣는다(1~2줄에는 날짜·숫자 설명 금지). | |
| 가운데 | 기능·항목은 **첫째·둘째·셋째**로 센다. | "첫째, ~인데요." |
| 끝 줄 | **"~까지 전부 정리해 놨으니까, 아무 댓글이나 남겨주시고 받아가세요."** | "사용법부터 꿀팁까지 전부 정리해 놨으니까, 아무 댓글이나 남겨주시고 받아가세요." |

## 말투
- 숫자는 **읽는 말로** 쓴다. (예: 3가지 → 세 가지, 2026년 → 이천이십육 년, 50% → 오십 퍼센트)
- 문장은 끊지 말고 **"~인데요, ~거든요"**처럼 이어서 쓴다.
- 목소리로 읽을 대본이므로 괄호·기호·영어 약어는 읽는 말로 풀어 쓴다.

## 다 쓴 뒤 확인
- [ ] 줄 수 10~13줄
- [ ] 1줄이 "여러분,"으로 시작하고 2초 안에 끝남, 이전과 다른 말
- [ ] 2줄이 충격 + 이유 꼴
- [ ] 날짜·숫자 설명이 3줄 이후에만 있음
- [ ] 항목을 첫째·둘째·셋째로 셈
- [ ] 숫자가 모두 읽는 말
- [ ] 끝 줄이 정해진 문장 꼴
