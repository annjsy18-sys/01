# 4. 소리

## 속도
- **완성본만** 살짝 빠르게 한다. **음높이는 그대로.** (기본 1.1배, ffmpeg `atempo` 같은 음높이 유지 방식)
- 편집 중간 파일에는 속도를 바꾸지 않는다.

## 배경 음악
- 목소리보다 **훨씬 작게** 깐다. (기본: 목소리보다 약 20dB 작게)
- 음악은 **원래 속도**로 깐다(완성본 속도 올리기에서 음악은 빼고 맞춘다).
- 끝에서 **서서히 줄인다.** (기본 마지막 2초 페이드아웃)

## 효과음
- **장면이 바뀔 때만**, 영상 하나에 **열 개 안팎.**
- 단어마다 반짝 소리 **금지.**

## 전체 소리 크기
- 유튜브·인스타 권장 크기에 맞춘다: **통합 소리 크기 -14 LUFS, 최대 -1 dBTP.**
