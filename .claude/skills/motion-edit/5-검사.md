# 5. 검사

사용자가 보기 **전에** 아래를 모두 검사한다. **문제가 있으면 고친 다음에 보여 준다.**

## 검사 항목

| 항목 | 기준 | 방법 예시 |
|---|---|---|
| 멈춘 화면 | **0개** | ffmpeg `freezedetect`로 확인 |
| 잘린 글자 | **0개** | 장면별 사진을 보고 자막·카드 글자가 화면 밖이나 상자 밖으로 잘렸는지 확인 |
| 소리 크기 | -14 LUFS 안팎, 최대 -1 dBTP 이하 | ffmpeg `loudnorm`/`ebur128`로 측정 |

## 장면별 사진
- **장면마다 사진 1장씩** 뽑아 **직접 눈으로 확인**한다.
- 확인할 것: 첫 2~7초 흐르는 배경 위 겹침, 중요한 단어 그림·카드, 자막 위치·색(지난 단어 회색·지금 단어 흰색 굵게)·선택 상자.

## 보고
- 보여 줄 때 검사 결과(멈춘 화면 수, 잘린 글자 수, 측정한 소리 크기)를 함께 적는다.
- 고친 것이 있으면 무엇을 고쳤는지 한 줄씩 적는다.
