# 모션 편집

세로 쇼츠를 만들 때마다 이 폴더의 규칙 파일 5개를 **처음부터 끝까지 먼저 읽고**, 아래 순서를 건너뛰지 않고 그대로 지킨다.

## 작업 순서

| 단계 | 할 일 | 규칙 파일 |
|---|---|---|
| 1. 레퍼런스 뜯어보기 | 잘 된 쇼츠의 말·화면이 바뀌는 순간을 장면 순서표로 먼저 적는다 | [2-박자.md](2-박자.md) |
| 2. 대본 | 10~13줄, 40~60초 대본을 쓴다 | [1-대본.md](1-대본.md) |
| 3. 단어 시각표 | 목소리를 먼저 만들고 받아 적어 단어마다 시각을 적는다 | [2-박자.md](2-박자.md) |
| 4. 장면표 | 문장 1줄 = 장면 1개로 장면표를 만든다 | [2-박자.md](2-박자.md) |
| 5. 화면 | 배경·카드·자막을 만든다 | [3-화면.md](3-화면.md) |
| 6. 소리 | 속도·배경 음악·효과음·소리 크기를 맞춘다 | [4-소리.md](4-소리.md) |
| 7. 검사 | 보여 주기 전에 검사하고, 문제가 있으면 고친 다음에 보여 준다 | [5-검사.md](5-검사.md) |

## 지킬 것

- 단계 순서를 바꾸지 않는다. 앞 단계 결과물(장면 순서표, 대본, 단어 시각표, 장면표)은 파일로 남기고 다음 단계에서 그대로 쓴다.
- 규칙과 다르게 해야 할 이유가 생기면, 마음대로 바꾸지 말고 먼저 사용자에게 묻는다.
- 검사(7단계)를 통과하지 못한 영상은 사용자에게 보여 주지 않는다.
